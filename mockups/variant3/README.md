# Ambedkarite Buddhist Community - Variant 3 Mockup

## Design Style: Vibrant & Modern

This is a fully clickable HTML mockup featuring a bold, energetic design with vibrant colors and modern UI patterns.

## Features

### Design Elements
- **Bold gradient backgrounds** using primary saffron (#E8B20E) and secondary blue (#2D4D9B)
- **Modern typography** with Poppins for headings and Noto Sans for body text
- **Dynamic animations** and scroll reveal effects
- **Vibrant accent colors** for visual hierarchy (#FF6B35, #00D9C0, #7F56D9)
- **Geometric shapes** and modern card-based layouts
- **Glassmorphism effects** on navigation
- **Bold CTAs** with gradient buttons

### Pages Included

1. **index.html** - Home page with hero section, stats, events preview, and donation goals
2. **about.html** - Mission, vision, values, leadership team (8 members)
3. **events.html** - Event listing with filters (12 events across 6 categories)
4. **event-detail.html** - Detailed event page with schedule and registration form
5. **donations.html** - 3 fundraising goals with progress bars and donation form
6. **membership.html** - 4 membership tiers (Student, Individual, Family, Lifetime) with sign-up form
7. **students.html** - Two tabs: "Moving to Canada" and "Current Students" resources
8. **gallery.html** - Photo gallery grid (24 images) with lightbox functionality and video section
9. **contact.html** - Contact form with map placeholder and FAQs

## Design Highlights

### What Makes This Variant Different

**Variant 3 (Vibrant & Modern)** vs Other Variants:
- More bold and colorful compared to Variant 1 (Clean & Minimalist)
- Uses gradients and vibrant accents unlike Variant 2 (Traditional & Spiritual)
- Targets younger, tech-savvy audience
- Energetic feel with dynamic animations
- Modern UI patterns (glassmorphism, cards, gradients)
- Bold typography and strong visual hierarchy

### Key Design Decisions

1. **Gradients everywhere** - Creates depth and modern feel
2. **Large, bold headings** - Poppins font at 800 weight
3. **Animated elements** - Counter animations, scroll reveals
4. **Vibrant accent colors** - Orange, teal, purple for variety
5. **Card-based layouts** - Consistent hover effects
6. **Modern navigation** - Glassmorphism with blur effects
7. **Progress bars with shimmer** - Engaging visual feedback
8. **Featured membership tier** - Visual emphasis on "Popular" option
